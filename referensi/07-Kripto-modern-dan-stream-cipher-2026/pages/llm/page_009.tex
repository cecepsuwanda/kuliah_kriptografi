\section*{Operasi XOR}

\begin{itemize}
    \item Di dalam \textit{cipher} modern, operasi XOR adalah operasi yang paling sering digunakan
    \item Notasi: $\oplus$
    \item Operasi:
    \[
    \begin{aligned}
    0 \oplus 0 &= 0 & 0 \oplus 1 &= 1 \\
    1 \oplus 0 &= 1 & 1 \oplus 1 &= 0
    \end{aligned}
    \]
\end{itemize}
