6. Keystream dapat dihasilkan secara paralel

Salah satu karakteristik penting Salsa20 adalah setiap blok keystream bergantung 

pada key, nonce, dan counter.

Secara konseptual:

      Key + Nonce + Counter 0 → Keystream 0

      Key + Nonce + Counter 1 → Keystream 1

      Key + Nonce + Counter 2 → Keystream 2

      Key + Nonce + Counter 3 → Keystream 3

Blok-blok tersebut pada prinsipnya dapat dihitung secara independen. Ini berbeda 

dari beberapa konstruksi stream cipher yang memiliki ketergantungan berantai 

antar keystream.
