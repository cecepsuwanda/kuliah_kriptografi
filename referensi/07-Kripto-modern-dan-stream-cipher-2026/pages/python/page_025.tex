           - 1 bit plainteks   1 bit kunci, atau

           - 1 byte plainteks  1 byte skunci, atau

           - n bit plainteks  n bit kunci

   setiap kali enkripsi

            - 1 bit cipherteks   1 bit kunci, atau

            - n bit cipherteks  n bit kunci

   setiap kali dekripsi.
