(a) Skema enkripsi mode CBC

\begin{itemize}
    \item[Encryption:]
    \[ C_0 = \text{IV} \]
    \[ C_i = E_K (P_i \oplus C_{i-1}) \]
\end{itemize}

\vspace{30mm}

(b) Skema dekripsi mode CBC

\begin{itemize}
    \item[Decryption:]
    \[ C_0 = \text{IV} \]
    \[ P_i = D_K (C_i) \oplus C_{i-1} \]
\end{itemize}
