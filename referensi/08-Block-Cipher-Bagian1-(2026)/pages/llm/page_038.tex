\section*{Mode CFB}

\vspace{60mm}

\textbf{Enkripsi:}
\[ C_j = P_j \oplus MSB_s(E_K(X_j)) \]
\[ X_{j+1} = LSB_{b-s}(X_j) \parallel C_i \]

\textbf{Dekripsi:}
\[ P_j = C_i \oplus MSB_s(E_K(X_j)) \]
\[ X_{j+1} = LSB_{b-s}(X_j) \parallel C_i \]

\vspace{10mm}

Mode CFB mengoperasikan \textbf{block cipher seperti stream cipher!!}
