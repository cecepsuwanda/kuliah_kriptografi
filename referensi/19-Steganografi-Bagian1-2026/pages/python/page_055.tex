2. Acak 

• Untuk membuat penyembunyian pesan lebih aman, bit-bit pesan 

tidak disimpan pada pixel-pixel yang berurutan, namun dipilih 

secara acak. 

• Pembangkit bilangan acak-semu (PRNG: pseudo-random number 

generator) digunakan untuk membangkitkan bilangan acak.

• Umpan (seed) untuk pembangkit bilangan acak berlaku sebagai 

kunci (stego-key).
