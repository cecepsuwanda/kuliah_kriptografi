\section*{2. Capaian Pembelajaran Lulusan (CPL)}

CPL yang dibebankan pada mata kuliah ini mencakup kompetensi lulusan dalam aspek pengetahuan, keterampilan, dan sikap, sesuai dengan standar kurikulum program studi:

\begin{itemize}[leftmargin=*]
  \item \textbf{CPL-Pengetahuan:} Menguasai konsep teoritis matematika (teori bilangan, aljabar abstrak) dan prinsip keamanan informasi untuk menganalisis sistem kriptografi.
  \item \textbf{CPL-Keterampilan Umum:} Mampu menerapkan pemikiran logis, kritis, sistematis, dan inovatif dalam konteks pengembangan atau implementasi solusi keamanan data.
  \item \textbf{CPL-Keterampilan Khusus:} Mampu merancang, mengimplementasikan, dan mengevaluasi algoritma kriptografi (klasik dan modern) serta protokol keamanan menggunakan bahasa pemrograman (misal: C/Python).
  \item \textbf{CPL-Sikap:} Menunjukkan sikap bertanggung jawab dan etika profesional dalam penggunaan teknologi keamanan informasi.
\end{itemize}

\vspace{0.5cm}

% ============================================================
% 3. CAPAIAN PEMBELAJARAN MATA KULIAH (CPMK)
% ============================================================
\section*{3. Capaian Pembelajaran Mata Kuliah (CPMK)}

Setelah menyelesaikan mata kuliah ini, mahasiswa diharapkan mampu:

\begin{itemize}[leftmargin=*]
  \item \textbf{CPMK-1:} Menjelaskan konsep dasar keamanan informasi, terminologi kriptografi, teori informasi, dan landasan matematika (teori bilangan, aljabar abstrak) yang relevan.
  \item \textbf{CPMK-2:} Menganalisis dan mengimplementasikan algoritma kriptografi klasik (Substitusi, Transposisi, Vigenere, Hill, Enigma) serta melakukan kriptanalisis dasar.
  \item \textbf{CPMK-3:} Menganalisis dan mengimplementasikan algoritma kriptografi modern simetris (Stream Cipher, Block Cipher: DES, AES) dan mode operasinya.
  \item \textbf{CPMK-4:} Menganalisis dan mengimplementasikan algoritma kriptografi kunci publik (RSA, ElGamal, Diffie-Hellman, ECC) serta manajemen kunci.
  \item \textbf{CPMK-5:} Menerapkan fungsi hash, Message Authentication Code (MAC), tanda tangan digital, dan sertifikat digital untuk menjamin integritas dan otentikasi data.
  \item \textbf{CPMK-6:} Menjelaskan prinsip kerja Pembangkit Bilangan Acak (RNG) dan protokol kriptografi (SSL/TLS).
  \item \textbf{CPMK-7:} Menerapkan teknik steganografi dan watermarking untuk penyembunyian data.
\end{itemize}

% ============================================================
% 4. SUB-CPMK / INDIKATOR PENCAPAIAN
% ============================================================
\section*{4. Sub-CPMK / Indikator Pencapaian}

Penjabaran CPMK menjadi indikator yang lebih terukur:

\begin{itemize}[leftmargin=*]
  \item \textbf{Sub-CPMK 1.1:} Menjelaskan layanan keamanan (confidentiality, integrity, availability, non-repudiation) dan sejarah kriptografi.
  \item \textbf{Sub-CPMK 1.2:} Menghitung entropi dan laju bahasa dalam konteks teori informasi.
  \item \textbf{Sub-CPMK 1.3:} Menerapkan teori bilangan (aritmetika modular, prima, Euclid) dan aljabar abstrak (grup, ring, field, Galois Field) dalam kriptografi.
  \item \textbf{Sub-CPMK 2.1:} Mengimplementasikan cipher klasik (Caesar, Vigenere, Playfair, Affine, Hill) dan teknik frekuensi analisis.
  \item \textbf{Sub-CPMK 3.1:} Menjelaskan prinsip stream cipher (LFSR, RC4) dan block cipher (Feistel, SPN).
  \item \textbf{Sub-CPMK 3.2:} Mengimplementasikan dan menganalisis keamanan DES dan AES (termasuk operasi S-Box, ShiftRows, MixColumns).
  \item \textbf{Sub-CPMK 3.3:} Membandingkan mode operasi block cipher (ECB, CBC, CFB, OFB, CTR).
  \item \textbf{Sub-CPMK 4.1:} Menjelaskan konsep kriptografi kunci publik dan masalah matematika yang mendasarinya (faktorisasi, logaritma diskrit).
  \item \textbf{Sub-CPMK 4.2:} Mengimplementasikan algoritma RSA, ElGamal, dan pertukaran kunci Diffie-Hellman.
  \item \textbf{Sub-CPMK 5.1:} Mengimplementasikan fungsi hash (MD5, SHA) dan menjelaskan konsep collision.
  \item \textbf{Sub-CPMK 5.2:} Menerapkan skema tanda tangan digital (DSA, RSA-Sig) dan memahami struktur sertifikat digital (X.509).
  \item \textbf{Sub-CPMK 6.1:} Membedakan PRNG dan TRNG serta menguji keacakan deret bit (misal: uji NIST).
  \item \textbf{Sub-CPMK 7.1:} Mengimplementasikan metode LSB untuk steganografi pada citra digital.
\end{itemize}

\section*{5. Materi Pembelajaran (Bahan Kajian)}

Daftar topik materi yang disusun berdasarkan literatur utama (Rinaldi Munir) dan standar akademik:

\begin{enumerate}[leftmargin=*]
  \item \textbf{Pengantar Kriptografi:} Definisi, terminologi, sejarah, layanan keamanan (CIA), kriptanalisis dasar.
  \item \textbf{Landasan Matematika \& Teori Informasi:}
    \begin{itemize}
        \item Teori Informasi: Entropy, laju bahasa.
        \item Teori Bilangan: Pembagian bulat, PBB, Algoritma Euclidean, Aritmetika Modulo, Bilangan Prima, Invers Modulo, Chinese Remainder Theorem.
        \item Aljabar Abstrak: Grup, Ring, Field, Finite Fields (GF), Aritmetika Polinom di GF($2^n$).
    \end{itemize}
  \item \textbf{Kriptografi Klasik:} 
    \begin{itemize}
        \item Cipher Substitusi (Caesar, Monoalfabetik, Homofonik, Poligram).
        \item Cipher Transposisi, Super Enkripsi.
        \item Vigenere Cipher (dan variannya), Playfair Cipher, Affine Cipher, Hill Cipher, Enigma Cipher.
        \item One-Time Pad (OTP).
    \end{itemize}
  \item \textbf{Kriptografi Modern Simetris:}
    \begin{itemize}
        \item Stream Cipher: OTP sebagai stream cipher, LFSR, RC4, A5, ChaCha20.
        \item Block Cipher: Prinsip perancangan (Confusion \& Diffusion, Feistel Network), DES, Triple DES, AES (Rijndael), Mode Operasi (ECB, CBC, CFB, OFB, CTR).
    \end{itemize}
  \item \textbf{Kriptografi Kunci Publik (Asimetris):} Konsep kunci publik/privat, RSA, Diffie-Hellman Key Exchange, ElGamal, Rabin, Elliptic Curve Cryptography (ECC), Knapsack (Merkle-Hellman).
  \item \textbf{Fungsi Hash \& Integritas Data:} Sifat hash satu arah, MD5, SHA (SHA-1, SHA-2, SHA-3), Message Authentication Code (MAC), HMAC.
  \item \textbf{Tanda Tangan Digital \& PKI:} Digital Signature Algorithm (DSA), Sertifikat Digital (X.509), Public Key Infrastructure (PKI).
  \item \textbf{Pembangkit Bilangan Acak (RNG):} PRNG vs TRNG, Linear Congruential Generator (LCG), Blum Blum Shub, Uji Keacakan.
  \item \textbf{Protokol \& Aplikasi:} SSL/TLS, SSH, PGP, Kriptografi pada E\-commerce/Blockchain.
  \item \textbf{Steganografi \& Watermarking:} Sejarah, Metode LSB (Least Significant Bit), Steganalis, Watermarking citra/audio.
\end{enumerate}

% 6. METODE PEMBELAJARAN

\section*{6. Metode Pembelajaran}

Pendekatan \textit{Student-Centered Learning} (SCL) digunakan untuk mencapai CPL:
\begin{itemize}[leftmargin=*]
  \item \textbf{Kuliah Interaktif \& Diskusi:} Pemaparan konsep teoritis dan diskusi kelas mengenai studi kasus keamanan.
  \item \textbf{Problem-Based Learning (PBL):} Penyelesaian masalah kriptanalisis atau desain protokol sederhana.
  \item \textbf{Project-Based Learning (PjBL):} Tugas besar implementasi algoritma kriptografi (misal: membuat aplikasi chat aman atau steganografi tools) secara berkelompok.
  \item \textbf{Praktikum Laboratorium:} Implementasi algoritma (C/Python) dan penggunaan tools kriptanalisis.
\end{itemize}

% 7. PENGALAMAN BELAJAR MAHASISWA

\section*{7. Pengalaman Belajar Mahasiswa}

\begin{itemize}[leftmargin=*]
  \item Mengerjakan latihan soal aritmetika modular dan teori bilangan.
  \item Mengimplementasikan cipher klasik (Vigenere, Playfair) dan melakukan pemecahan sandi (breaking cipher) sederhana.
  \item Membangun program simulasi DES/AES atau menggunakan library kriptografi (OpenSSL/\allowbreak PyCryptodome) untuk memahami mode operasi.
  \item Melakukan pembangkitan kunci RSA dan simulasi pertukaran pesan terenkripsi antar mahasiswa.
  \item Menganalisis sertifikat digital pada browser web (HTTPS).
  \item Mengimplementasikan teknik penyembunyian pesan (steganografi) pada file gambar bmp/png.
\end{itemize}
