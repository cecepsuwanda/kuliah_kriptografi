\section{Fungsi Hash}

Fungsi hash kriptografis memetakan input berukuran sembarang ke output berukuran tetap (misalnya 256 bit). Sifat penting:

\begin{itemize}
\item \textbf{Preimage resistance:} Sulit menemukan $x$ jika diberikan $h(x)$.
\item \textbf{Second preimage resistance:} Sulit menemukan $x' \neq x$ dengan $h(x') = h(x)$.
\item \textbf{Collision resistance:} Sulit menemukan $x, x'$ dengan $x \neq x'$ dan $h(x) = h(x')$.
\end{itemize}

Aplikasi: verifikasi integritas file, penyimpanan kata sandi, tanda tangan digital.
