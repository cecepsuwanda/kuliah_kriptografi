\chapter{Daftar Modul Sumber}

Seluruh materi buku ini bersumber dari 19 modul bahan kuliah IF4020 Kriptografi,
Rinaldi Munir, Program Studi Teknik Informatika, STEI, Institut Teknologi
Bandung, 2026. Salinan lokal setiap modul tersedia di folder \texttt{referensi/}.
Nomor modul mengikuti nama folder; tidak ada folder bernomor 12.

\begin{enumerate}[leftmargin=*]
    \item \textit{Pengantar Kriptografi}.
    \item \textit{Landasan Matematika untuk Kriptografi}.
    \item \textit{Kriptografi Klasik (Bagian 1)}.
    \item \textit{Kriptografi Klasik (Bagian 2)}.
    \item \textit{One-Time Pad, cipher yang tidak dapat dipecahkan}.
    \item \textit{Serangan Terhadap Kriptografi}.
    \item \textit{Kriptografi Modern dan Stream Cipher}.
    \item \textit{Block Cipher (Bagian 1)}.
    \item \textit{Review Beberapa Block Cipher (Bagian 1: DES dan Triple DES)}.
    \item \textit{Review Beberapa Block Cipher (Bagian 2: AES)}.
    \item \textit{Review Beberapa Block Cipher (Bagian 3: GOST, RC5, RC6,
          Serpent, dan cipher sejenis)}.
    \item \textit{Algoritma RSA}.
    \item \textit{Algoritma ElGamal}.
    \item \textit{Algoritma Pertukaran Kunci Diffie-Hellman}.
    \item \textit{Algoritma Kriptografi Knapsack}.
    \item \textit{Elliptic Curve Cryptography (Bagian 1)}.
    \item \textit{ECC Bagian 2}.
    \item \textit{Steganografi (Bagian 1)}.
    \item \textit{Steganalisis}.
\end{enumerate}

Modul 19 dan 20 tidak dijadikan bab, tetapi menjadi bagian cakupan mata kuliah
pada RPS.
