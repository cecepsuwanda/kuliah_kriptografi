\section{Message Authentication Code (MAC)}
\label{sec:mac}

Modul sumber yang menjadi acuan bab ini tidak membahas \textit{Message
Authentication Code} (MAC). Karena itu, bab ini tidak menjelaskan konsep,
konstruksi, maupun penggunaan MAC. Bagian ini dicantumkan hanya untuk menandai
batas cakupan bab.
