% --- Hyphenation hints ---------------------------------------------------
% Indonesian hyphenation patterns (babel) do not cover these English /
% technical terms, which otherwise produce loose or overfull lines.
% Must be given per-language: a plain \hyphenation in the preamble would be
% registered for the default language, not for the active (indonesian) one.
\babelhyphenation[indonesian]{su-per-in-creas-ing non-su-per-in-creas-ing Po-ly-al-pha-be-tic}
