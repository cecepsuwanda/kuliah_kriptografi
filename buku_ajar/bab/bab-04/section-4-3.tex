\section{Cipher Vigenère}

\subsection{Konsep}

Cipher Vigenère adalah cipher substitusi polialfabetik yang menggunakan kata kunci berulang untuk menentukan pergeseran setiap huruf. Setiap huruf plaintext digeser dengan jumlah yang sesuai dengan posisi huruf tersebut dalam kata kunci. Jika plaintext lebih panjang dari kata kunci, kunci diulang dari awal.

Cipher Vigenère dikembangkan pada abad ke-16 dan merupakan cipher polialfabetik yang menggunakan kata kunci berulang \cite{stallings2017}. Dengan variasi shift per huruf, Vigenère lebih tahan terhadap analisis frekuensi huruf tunggal dibanding Caesar. Namun, jika kunci pendek, pola berulang memungkinkan serangan Kasiski.

\subsection{Tabula Vigenère}

Tabula Vigenère dibangun dengan mengisi alfabet 26x26. Setiap baris dimulai dengan huruf kunci pertama, diikuti oleh huruf-huruf berikutnya secara berurutan. Baris berikutnya diisi dengan huruf yang digeser sesuai dengan shift yang ditentukan oleh huruf tersebut dalam kata kunci.

\subsection{Algoritma Enkripsi}

Untuk setiap huruf $p_i$ di plaintext:
\begin{enumerate}
  \item Tentukan posisi huruf $p_i$ dalam alfabet (0-25)
  \item Tentukan posisi huruf $k_i$ dalam kata kunci (jika ada, gunakan Z)
  \item Hitung $c_i = (p_i + k_i) \bmod 26$
\end{enumerate}

\subsection{Contoh Enkripsi}

Plaintext: HELLO, kunci: LEMON.

\begin{itemize}
  \item H: posisi 7, kunci L: posisi 11 $\rightarrow$ $7 + 11 = 18 \equiv 18 \bmod 26 = \textbf{S}$
  \item E: posisi 4, kunci E: posisi 4 $\rightarrow$ $4 + 4 = 8 \equiv 8 \bmod 26 = \textbf{I}$
  \item L: posisi 11, kunci M: posisi 12 $\rightarrow$ $11 + 12 = 23 \equiv 23 \bmod 26 = \textbf{X}$
  \item L: posisi 11, kunci O: posisi 14 $\rightarrow$ $11 + 14 = 25 \equiv 25 \bmod 26 = \textbf{Z}$
  \item O: posisi 14, kunci N: posisi 13 $\rightarrow$ $14 + 13 = 27 \equiv 1 \bmod 26 = \textbf{B}$
\end{itemize}

Ciphertext: SIXZB

\subsection{Kelemahan}

Cipher Vigenère rentan terhadap \textbf{frequency analysis} jika kunci pendek dan hanya sedikit kata kunci. Namun, dengan kunci yang panjang dan variasi shift, cipher menjadi jauh lebih sulit dipecahkan. Kasiski mengembangkan \textbf{index of coincidence} untuk mengukurangi keberhasilan analisis frekuensi.

\begin{catatan}
Vigenère dengan kunci panjang dan acak (random) secara signifikan lebih aman dari Caesar cipher.
\end{catatan}

\subsection{Implementasi dalam C}

\begin{lstlisting}[style=cstyle, caption={Vigenère Cipher dalam C}]
#include <stdio.h>
#include <string.h>
#include <ctype.h>

void vigenere_encrypt(const char *plaintext, const char *key, char *ciphertext) {
    int len = strlen(plaintext);
    int key_len = strlen(key);
    
    for (int i = 0; i < len; i++) {
        if (isalpha(plaintext[i])) {
            char base = isupper(plaintext[i]) ? 'A' : 'a';
            int k = toupper(key[i % key_len]) - 'A';
            int c = (toupper(plaintext[i]) - base + k) % 26;
            ciphertext[i] = base + c;
        } else {
            ciphertext[i] = plaintext[i];
        }
    }
    ciphertext[len] = '\0';
}

void vigenere_decrypt(const char *ciphertext, const char *key, char *plaintext) {
    int len = strlen(ciphertext);
    int key_len = strlen(key);
    
    for (int i = 0; i < len; i++) {
        if (isalpha(ciphertext[i])) {
            char base = isupper(ciphertext[i]) ? 'A' : 'a';
            int k = toupper(key[i % key_len]) - 'A';
            int c = (toupper(ciphertext[i]) - base - k + 26) % 26;
            plaintext[i] = base + c;
        } else {
            plaintext[i] = ciphertext[i];
        }
    }
    plaintext[len] = '\0';
}

int main() {
    char msg[] = "ATTACKATDAWN";
    char encrypted[256];
    char decrypted[256];
    vigenere_encrypt(msg, "LEMON", encrypted);
    printf("Encrypted: %s\n", encrypted);
    vigenere_decrypt(encrypted, "LEMON", decrypted);
    printf("Decrypted: %s\n", decrypted);
    return 0;
}
\end{lstlisting}
