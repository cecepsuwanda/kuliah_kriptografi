\section{Kriptanalisis Mendalam}

\subsection{Differential Cryptanalysis}

Differential cryptanalysis adalah teknik analisis yang dikembangkan oleh Biham dan Shamir pada tahun 1990-an untuk menyerang cipher blok \cite{biham1993}. Teknik ini memanfaatkan perbedaan dalam ciphertext ketika plaintext diubah secara sistematis.

\textbf{Prinsip Dasar}: Jika kita dapat menemukan pasangan plaintext $(P, P')$ dengan perbedaan $\Delta P = P \oplus P'$ yang menghasilkan perbedaan ciphertext $\Delta C = C \oplus C'$ yang dapat diprediksi, maka kita dapat mengekstrak informasi tentang kunci.

\subsection{Differential Cryptanalysis terhadap DES}

DES adalah target pertama differential cryptanalysis karena strukturnya yang relatif sederhana \cite{biham1993}. Mari kita analisis DES dengan 3 round (reduced-round DES) untuk memahami konsepnya.

\textbf{S-Box DES}: Setiap S-box DES mengubah 6-bit input menjadi 4-bit output. Distribusi output untuk input yang berbeda 1 bit tidak seragam, yang menciptakan bias yang dapat dieksploitasi.

\textbf{Differential Characteristic}: Pola perbedaan yang konsisten melalui beberapa round.

\begin{contoh}
Differential characteristic untuk 2-round DES:
\begin{itemize}
  \item Input difference: $\Delta P = 0x00800000000000000$ (hanya bit 3 yang berbeda)
  \item Setelah round 1: $\Delta_1 = 0x00000020000000000$ (bit 18 berbeda)
  \item Setelah round 2: $\Delta_2 = 0x00000002000000000$ (bit 22 berbeda)
  \item Probabilitas: $2^{-14}$ (sangat rendah)
\end{itemize}
\end{contoh}

// Calculate difference between two values
uint64_t calculate_diff(uint64_t a, uint64_t b) {
    return a ^ b;
}

// Analyze differential characteristic
void analyze_differential(uint64_t plaintext1, uint64_t plaintext2, 
                         uint64_t key, int rounds) {
    uint64_t state1 = plaintext1;
    uint64_t state2 = plaintext2;
    
    printf("Round 0: Diff = %016lx\n", calculate_diff(state1, state2));
    
    for (int round = 1; round <= rounds; round++) {
        des_round(&state1, key);
        des_round(&state2, key);
        
        uint64_t diff = calculate_diff(state1, state2);
        printf("Round %d: Diff = %016lx\n", round, diff);
    }
}

// Find high-probability differentials
void find_differentials() {
    int count[65536] = {0}; // 16-bit differences
    uint64_t key = 0x0123456789ABCDEF; // Test key
    
    // Test all possible input differences
    for (int i = 0; i < 65536; i++) {
        for (int j = 0; j < 65536; j++) {
            uint64_t p1 = i, p2 = j;
            uint64_t diff = calculate_diff(p1, p2);
            
            if (diff == 0x00000000000000000) continue; // Skip zero difference
            
            uint64_t c1 = encrypt_des(p1, key, 1); // 1 round
            uint64_t c2 = encrypt_des(p2, key, 1);
            uint64_t output_diff = calculate_diff(c1, c2);
            
            count[output_diff & 0xFFFF]++;
        }
    }
    
    // Find most common output differences
    int max_count = 0;
    int best_diff = 0;
    for (int i = 0; i < 65536; i++) {
        if (count[i] > max_count) {
            max_count = count[i];
            best_diff = i;
        }
    }
    
    printf("Best differential: 0x%04x (count = %d)\n", best_diff, max_count);
}

\subsection{Linear Cryptanalysis}

Linear cryptanalysis adalah teknik lain yang dikembangkan oleh Matsui pada tahun 1993 \cite{matsui1993}. Teknik ini mencari persamaan linear antara bit-bit plaintext, kunci, dan ciphertext.

\textbf{Persamaan Linear}: 
\[
P_{i_1} \oplus P_{i_2} \oplus \cdots \oplus P_{i_u} \oplus K_{j_1} \oplus K_{j_2} \oplus \cdots \oplus K_{j_v} = C_{k_1} \oplus C_{k_2} \oplus \cdots \oplus C_{k_w}
\]

\textbf{Bias}: Persamaan linear tidak selalu benar dengan probabilitas 0.5. Jika probabilitasnya menyimpang dari 0.5, kita dapat mengekstrak bit kunci.

\begin{contoh}
Linear approximation untuk DES S-box:
\[
S_{box}[0x0F]_{(7)} \oplus S_{box}[0x0F]_{(2)} \oplus S_{box}[0x0F]_{(1)} = K_{5} \oplus C_{8}
\]
dengan probabilitas 0.75 (bias 0.25).
\end{contoh}

\subsection{Countermeasures terhadap Cryptanalysis}

Cipher modern dirancang untuk resisten terhadap differential dan linear cryptanalysis:

\textbf{DES Countermeasures}:
\begin{itemize}
  \item DES menggunakan 16 round untuk membuat differential attack tidak praktis
  \item S-box DES dirancang untuk meminimalkan bias linear
  \item Permutation P menyebarkan efek local ke seluruh state
\end{itemize}

\textbf{AES Countermeasures}:
\begin{itemize}
  \item S-box AES berdasarkan inversi multiplicative di $\mathrm{GF}(2^8)$
  \item MixColumns menyediakan diffusion yang kuat
  \item Key schedule yang kompleks
\end{itemize}

// Differential attack on 3-round DES
int differential_attack_3_round() {
    // Known plaintext pair with specific difference
    uint64_t p1 = 0x123456789ABCDEF0;
    uint64_t p2 = 0x103456789ABCDEF0; // Difference in bit 4
    
    // Collect ciphertexts
    uint64_t c1[256], c2[256];
    uint64_t keys[256];
    
    // Generate 256 possible keys
    for (int i = 0; i < 256; i++) {
        keys[i] = i; // Simplified key space
        c1[i] = des_3_round(p1, keys[i]);
        c2[i] = des_3_round(p2, keys[i]);
    }
    
    // Find key that produces expected output difference
    uint64_t expected_diff = 0x00000000000000008; // Expected difference
    
    for (int i = 0; i < 256; i++) {
        if ((c1[i] ^ c2[i]) == expected_diff) {
            printf("Possible key found: 0x%02x\n", i);
            return i;
        }
    }
    
    printf("No key found\n");
    return -1;
}

\subsection{Implikasi untuk Keamanan Modern}

Pemahaman cryptanalysis sangat penting untuk:

\begin{itemize}
  \item \textbf{Desain Cipher}: Mengetahui kelemahan untuk merancang cipher yang lebih kuat
  \item \textbf{Implementasi Aman}: Menghindari implementasi yang rentan terhadap side-channel
  \item \textbf{Evaluasi Keamanan}: Menilai kekuatan cipher yang ada
  \item \textbf{Standar Industri}: Memahami mengapa standar tertentu dipilih
\end{itemize}

\begin{catatan}
Differential dan linear cryptanalysis adalah teknik analisis fundamental dalam kriptografi modern. Meskipun cipher modern seperti AES dirancang untuk resisten terhadap serangan ini, pemahaman teknik ini tetap penting untuk kriptografer dan analis keamanan.
\end{catatan}
