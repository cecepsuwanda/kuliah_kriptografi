\section{Ikhtisar Materi per Bab}

Struktur kurikulum kriptografi dirancang sistematis dari konsep dasar hingga aplikasi modern, dengan tiap bab mengintegrasikan teori, implementasi, dan analisis keamanan. Setiap bab dibangun di atas fondasi bab sebelumnya, menciptakan alur pembelajaran yang kohesif.

\subsection{Fondasi Konseptual (Bab II-III)}
\begin{enumerate}
  \setcounter{enumi}{1}
  \item \textbf{Bab II}: Pengantar kriptografi, layanan keamanan, ancaman, terminologi, serta simetris vs asimetris
  \begin{itemize}
    \item Menjawab: "Mengapa kita perlu kriptografi?"
    \item Membangun pemahaman tentang landscape keamanan informasi
    \item Menyiapkan konteks untuk kebutuhan matematika
  \end{itemize}
  \item \textbf{Bab III}: Aritmetika modular, Euclid, teori bilangan, fast exponentiation, implementasi C
  \begin{itemize}
    \item Menjawab: "Bagaimana matematika membuat kriptografi mungkin?"
    \item Setiap konsep matematika langsung diaplikasikan dalam Bab IV
    \item Fondasi untuk algoritma modern di Bab V-VII
  \end{itemize}
\end{enumerate}

\subsection{Aplikasi dan Implementasi (Bab IV-VII)}
\begin{enumerate}
  \setcounter{enumi}{3}
  \item \textbf{Bab IV}: Cipher klasik (Caesar, Vigenère, substitusi), kriptanalisis dasar, implementasi C
  \begin{itemize}
    \item Penerapan langsung matematika Bab III
    \item Memperkenalkan konsep enkripsi/dekripsi sederhana
    \item Menunjukkan kelemahan yang memotivasi algoritma modern
  \end{itemize}
  \item \textbf{Bab V}: Stream/block cipher, DES, AES, dan mode operasi (ECB, CBC, CFB, OFB, CTR)
  \begin{itemize}
    \item Evolusi dari cipher klasik ke modern
    \item Matematika Bab III diterapkan dalam desain AES
    \item Konsep mode operasi untuk aplikasi dunia nyata
  \end{itemize}
  \item \textbf{Bab VI}: Kriptografi kunci publik, RSA, pertukaran kunci, implementasi C
  \begin{itemize}
    \item Teori bilangan prima dari Bab III menjadi dasar keamanan RSA
    \item Menjawab masalah distribusi kunci dari kriptografi simetris
  \end{itemize}
  \item \textbf{Bab VII}: Fungsi hash, MAC, integritas data, tanda tangan digital
  \begin{itemize}
    \item Melengkapi layanan keamanan dari Bab II
    \item Mengintegrasikan konsep dari Bab V-VI
  \end{itemize}
\end{enumerate}

\subsection{Integrasi dan Analisis (Bab VIII-X)}
\begin{enumerate}
  \setcounter{enumi}{7}
  \item \textbf{Bab VIII}: RNG, protokol (TLS/SSH/PGP dasar), manajemen kunci dan PKI
  \begin{itemize}
    \item Menggabungkan semua konsep sebelumnya dalam protokol nyata
    \item Menunjukkan bagaimana komponen kriptografi bekerja bersama
  \end{itemize}
  \item \textbf{Bab IX}: Kriptanalisis (frequency analysis, Kasiski) sebagai pendalaman keamanan
  \begin{itemize}
    \item Menerapkan statistik dan probabilitas untuk memecahkan cipher
    \item Memperdalam pemahaman tentang mengapa suatu cipher aman atau tidak
  \end{itemize}
  \item \textbf{Bab X}: Evaluasi komprehensif, refleksi, dan integrasi kompetensi
  \begin{itemize}
    \item Mengintegrasikan seluruh materi dalam studi kasus komprehensif
    \item Memvalidasi pencapaian semua Sub-CPMK
  \end{itemize}
  \item \textbf{Bab XI (tambahan)}: Steganografi dan watermarking
\end{enumerate}

Alur ini memastikan mahasiswa membangun fondasi matematis terlebih dahulu, lalu beralih ke implementasi algoritma, protokol, serta analisis keamanan. Setiap transisi dirancang untuk menjawab pertanyaan "mengapa topik ini penting?" dengan menghubungkan ke materi sebelumnya dan mempersiapkan untuk materi berikutnya. Bab penutup mengintegrasikan keseluruhan capaian untuk menilai kompetensi secara menyeluruh dan memandu langkah belajar lanjutan.
