\begin{rangkuman}
Bab ini memperkenalkan tujuan buku ajar, keterkaitannya dengan RPS berbasis OBE
(CPMK-1 dan CPMK-2), petunjuk penggunaan, serta konteks kurikulum.

\textbf{Poin Kunci:}
\begin{itemize}
  \item Buku ini dirancang dengan pendekatan OBE yang fokus pada pencapaian kompetensi terukur
  \item Setiap bab dipetakan ke Sub-CPMK 2.1--2.3 dan 1.1--1.4
  \item Outcome utama: mengenal algoritma serta memahami konsep dan urgensi di TI
  \item Contoh kode C bersifat demonstrasi, bukan target implementasi penuh
\end{itemize}
\end{rangkuman}

% ============================================================
% Persiapan untuk Bab Berikutnya
% ============================================================
\begin{transition}
Setelah memahami struktur dan pendekatan pembelajaran dalam buku ini, kita akan memasuki \textbf{Bab II: Landasan Teori dan Konsep Dasar Kriptografi}. 

Dalam Bab II, Anda akan:
\begin{itemize}
  \item Memahami \textit{big picture} keamanan informasi: mengapa kriptografi diperlukan (urgensi di TI)
  \item Mengenal terminologi dasar: plaintext, ciphertext, cipher, key
  \item Memahami layanan keamanan: kerahasiaan (\textit{confidentiality}),
        integritas, ketersediaan, dan anti-penyangkalan (\textit{non-repudiation})
  \item Mengenali model komunikasi aman dan ancaman yang ada
\end{itemize}

Pemahaman konsep dasar ini menjadi fondasi sebelum matematika pengantar di Bab III dan algoritma di bab berikutnya.
\end{transition}
