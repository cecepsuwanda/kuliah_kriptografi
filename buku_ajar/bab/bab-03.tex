\begin{asesmen}
\textbf{Instrumen Penilaian untuk Sub-CPMK 1.3}

\textbf{A. Pilihan Ganda}

\begin{enumerate}
  \item Invers modular dari $a$ modulo $n$ hanya ada jika:
  \begin{enumerate}
    \item $a > n$
    \item $\gcd(a, n) = 1$
    \item $a$ prima
    \item $n$ prima
  \end{enumerate}
  
  \item Algoritma fast exponentiation untuk menghitung $a^b \bmod n$ memiliki kompleksitas waktu:
  \begin{enumerate}
    \item $O(b)$
    \item $O(\log b)$
    \item $O(n)$
    \item $O(a)$
  \end{enumerate}
  
  \item Untuk $n = p \cdot q$ dengan $p, q$ prima, $\varphi(n)$ sama dengan:
  \begin{enumerate}
    \item $p + q$
    \item $p \cdot q$
    \item $(p-1)(q-1)$
    \item $p - q$
  \end{enumerate}
\end{enumerate}

\textbf{B. Essay dan Coding}

\begin{enumerate}
  \item Jelaskan algoritma Euclid diperluas dan kegunaannya dalam kriptografi.
  
  \item Implementasikan dalam C: \code{mod\_inverse(a, m)} yang mengembalikan $-1$ jika invers tidak ada.
\end{enumerate}

\textbf{Rubrik Penilaian}: Lihat Lampiran A
\end{asesmen}

\begin{rangkuman}
Bab ini membahas fondasi matematika kriptografi: aritmetika modular, algoritma Euclid dan Euclid diperluas, teori bilangan (prima, teorema Fermat dan Euler, CRT), aljabar abstrak (grup, ring, field, Galois Field $\mathrm{GF}(2^n)$), serta fast modular exponentiation. Konsep teori bilangan menjadi dasar RSA; konsep field menjadi dasar AES.

\textbf{Poin Kunci:}
\begin{itemize}
  \item Kongruensi modular: $a \equiv b \pmod{n}$ jika $n \mid (a-b)$
  \item Invers modular hanya ada jika $\gcd(a, n) = 1$
  \item Euclid diperluas: menghitung $\gcd$ sekaligus koefisien Bézout
    \item Chinese Remainder Theorem: menyelesaikan sistem kongruensi
  \item Grup, ring, field; $\mathrm{GF}(2^n)$ untuk operasi bit (misal AES)
  \item Fast exponentiation: $O(\log b)$ untuk menghitung $a^b \bmod n$
  \item $\varphi(n) = (p-1)(q-1)$ untuk $n = pq$
\end{itemize}

{\raggedright \textbf{Kata Kunci}: \crypt{Aritmetika Modular}, \crypt{Kongruensi}, \crypt{Algoritma Euclid}, \crypt{Invers Modular}, \crypt{Chinese Remainder Theorem}, \crypt{Galois Field}, \crypt{Fast Exponentiation}, \crypt{Fungsi Euler}\par}
\end{rangkuman}

\begin{transition}
Setelah mempelajari fondasi matematika kriptografi, kita siap untuk memasuki \textbf{Bab IV: Algoritma Kriptografi Klasik}.

Dalam Bab IV, kita akan menerapkan semua matematika yang telah dipelajari:
\begin{itemize}
  \item \textbf{Caesar Cipher}: Menggunakan aritmetika modular sederhana $(x + k) \bmod 26$
  \item \textbf{Vigenère Cipher}: Aplikasi modular arithmetic berulang
  \item \textbf{Affine Cipher}: Memerlukan invers modular dari koefisien
  \item \textbf{Hill Cipher}: Menggunakan aljabar linear dan invers matriks modular
  \item \textbf{Playfair Cipher}: Operasi modular pada pasangan huruf (digraph)
\end{itemize}

Setiap cipher akan kita:
\begin{enumerate}
  \item \textbf{Analisis matematisnya}: Mengapa cipher bekerja (atau tidak bekerja)?
  \item \textbf{Implementasikan dalam C}: Terapkan konsep matematika ke kode praktis
  \item \textbf{Kriptanalisis}: Pelajari mengapa cipher klasik tidak aman
\end{enumerate}

Pendekatan ini memastikan Anda tidak hanya memahami teori, tetapi juga melihat langsung bagaimana matematika diaplikasikan dalam implementasi nyata. Setelah menguasai cipher klasik, Anda akan siap untuk algoritma modern seperti AES dan RSA yang menggunakan prinsip matematika yang sama namun dengan kompleksitas yang jauh lebih tinggi.

\textbf{Preview}: Di Bab IV, kita akan mulai dengan Caesar cipher—penerapan paling sederhana dari modular arithmetic—sebelum bergerak ke cipher yang lebih kompleks yang menggabungkan multiple konsep matematika dari Bab III.
\end{transition}
